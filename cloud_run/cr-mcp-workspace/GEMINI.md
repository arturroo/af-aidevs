# cr-mcp-workspace - MCP Server for Isolated Workspaces

This server provides isolated workspace management for AI agents, allowing them to list, read, and write files within a secured directory structure on Cloud Run.

## Architecture & Security

### 1. Authentication (JWT / OIDC)
- The server requires a Google OIDC ID Token in the `Authorization: Bearer <token>` header.
- For local testing via impersonation, tokens generated by `gcloud auth print-identity-token` do NOT contain the email claim. The server maps the specific test `sub` ID `110832476443475170542` to the test identity `sa-cr-s01e05-agent-integration-test@af-aidevs.iam.gserviceaccount.com`.
- The domain part is stripped, but the `sa-` prefix is preserved for the workspace folder name (e.g., `sa-cr-s01e05-agent-integration-test`).

### 2. Isolation & Paths
- Every agent has a private root directory based on its identity and the `X-Session-ID` provided.
- **Physical Path:** `/workspace/<caller_identity_prefix>/<x_session_id>/`
- This ensures that agents cannot access or overwrite files belonging to other sessions or other agents.
- Path traversal attempts (using `..`) are strictly blocked and raise a `PermissionError`.

### 3. Session Headers
To interact with the server, the client MUST provide and manage two session headers:
1. `X-Session-ID`: Generated by the client/agent to identify the conversation/task session.
2. `mcp-session-id`: Generated by the FastMCP server during the SSE connection establishment. The client must capture this header and send it in subsequent POST requests.

### 4. Audit Logging (The Google Way)
- Every tool execution, access denied, or file not found event is logged to `stdout` as a structured JSON object.
- **Format:**
  ```json
  {
    "log_type": "AUDIT",
    "resource_name": "cr-mcp-workspace",
    "session_id": "...",
    "actor": "workspace",
    "content": "...",
    "metadata": { ... }
  }
  ```
- These logs are picked up by a Cloud Logging Sink and routed to BigQuery dataset `ai_governance`, table `run_googleapis_com_stdout`.
- Views `audit_v1` and `audit_v` are available to query these logs easily.

## How to use in Agents (Python Client Implementation)

When building an agent in Python that connects to this MCP server, the recommended way is to use the `FastMCP` native client with `StreamableHttpTransport`. This abstracts away the complexity of handling the SSE stream and JSON-RPC protocol.

### Python Implementation Example

```python
import os
from fastmcp import Client as FastMCPClient
from fastmcp.client.transports import StreamableHttpTransport
from google.auth.transport.requests import Request
from google.oauth2 import id_token

# Configuration
MCP_SERVER_URL = "https://cr-mcp-workspace-qsvqxjqyrq-oa.a.run.app"
SESSION_ID = "your-custom-session-id"

# Step 1: Obtain OIDC Token (Required for Cloud Run to Cloud Run communication)
# Standard Google SDKs (like BigQuery) handle this automatically, but for custom 
# Cloud Run services, we must fetch the token for the specific audience URL.
auth_req = Request()
OIDC_TOKEN = id_token.fetch_id_token(auth_req, MCP_SERVER_URL)

async def call_mcp_tool(tool_name: str, args: dict):
    mcp_endpoint = f"{MCP_SERVER_URL}/mcp"
    
    # We pass both headers. StreamableHttpTransport and FastMCPClient 
    # will handle the SSE connection and mcp-session-id automatically!
    transport = StreamableHttpTransport(
        url=mcp_endpoint, 
        headers={
            "X-Session-ID": SESSION_ID,
            "Authorization": f"Bearer {OIDC_TOKEN}"
        }
    )
    
    try:
        async with FastMCPClient(transport) as client:
            result = await client.call_tool(tool_name, args)
            
            # Handle result (FastMCP returns a string or object with content)
            if hasattr(result, 'content'):
                return result.content[0].text if result.content else ""
            return str(result)
            
    except Exception as e:
        print(f"MCP Call error: {e}")
        return str(e)

# Example usage:
# await call_mcp_tool("list_files", {"path": "."})
```

### Available Tools
- `list_files(path: str)`: Lists files in the isolated workspace.
- `read_file(file_path: str)`: Reads content of a file.
- `write_file(file_path: str, content: str)`: Writes content to a file.
